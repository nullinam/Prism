Privacy, in plain language

How PRISM handles files.

The browser trial is designed to process supported inputs on your device. This page describes what that means and the network activity involved in visiting the site.

PRISM browser trial · Privacy and network note · Updated October 17, 2026

Your files stay on this device.

PRISM processes selected file contents locally in your browser and does not upload those contents to PRISM servers. The website host may receive standard connection data when you visit.

What happens to a selected file

  • You choose a file through your browser. PRISM reads it in the page using browser file APIs and runs the tool locally.
  • PRISM has no file-upload API route or server-side file-processing service in this release.
  • Previews and outputs are created in the browser. You choose when to save or download a result; the original file is left unchanged.
  • File names and contents are not intentionally sent in analytics, error reports, or PRISM server logs. The app does not send tool inputs or outputs to a PRISM endpoint.

Limits and local browser storage

Each tool shows its file and batch limits before file selection. For example, the browser trial caps image inputs at 20 MiB per file and 40 megapixels per decoded image; PDF, document, and batch tools have their own smaller limits. PDF compression, known-password unlocking, AES-256 protection, and JPEG image extraction use a locally bundled QPDF WebAssembly engine in a browser worker. Password tools do not save passwords in task recovery. PDF image extraction exports directly embedded JPEG image objects only.

Theme and appearance preferences, recent tool names, and feedback drafts are saved in this browser’s local storage. Recent history stores tool names only, never selected file names or paths. When task recovery is enabled on a tool page, selected files and settings are saved in this browser’s IndexedDB so they can be restored after reload. This local copy can use significant device storage; disable recovery or clear the recovered task on the tool page, or clear this site’s browser storage. Password-generation and PDF-password tools keep recovery disabled. Trial run counters for some tools are kept in session storage and reset when the browser session ends. These values are not sent to PRISM servers by the app.

Feedback and external services

Feedback drafts stay in local storage until you choose to open GitHub Issues. GitHub is an external service and receives information according to its own privacy terms when you submit a report. Avoid including sensitive information. The browser trial does not collect payment details.

Network activity

When you visit PRISM, your browser requests the page and its application code, styles, and other static assets from the website host (Vercel). Like other web hosts, Vercel may process connection and request information needed to deliver, secure, and operate the site, such as IP address, requested URL, browser information, and request time. This is separate from the contents of a file you select.

The PRISM website source does not include an analytics SDK, advertising tracker, third-party script, or externally hosted font. PRISM Web Analytics is not configured in the application source. If analytics, crash reporting, payments, or other providers are added later, this page must be updated to identify what is sent and to whom.

See Vercel’s Privacy Notice for information about data Vercel processes as a hosting provider. If Vercel Web Analytics is enabled in a future release, its page-view data transmission is described in Vercel’s Analytics privacy details.

Verify the promise

You can inspect the browser’s Network panel while using a file tool. Requests needed to load PRISM should go to the website host. A file action should not create a request containing the selected file or its contents. The site also sets a Content Security Policy that restricts connections and scripts to the PRISM origin.

This is a product behavior statement, not a security certification. Browser extensions, malware, or other software on your device are outside PRISM’s control. Avoid selecting a file if your device or browser is not trusted.

Desktop and future apps

Desktop and mobile releases are not available from this website yet. Their file handling, updates, installer signing, and any network connections will be documented separately before those builds are offered.
